# evals

- `golden/`: set de oro (solo lectura).
- `run_eval.py`: script de evaluación (llega con `add-rag-core`).
- `baseline.json`: métricas de la línea base contra la que corre el gate de CI.
- `runs/`: salidas de cada corrida (ignoradas por git, salvo la línea base).
- `RESULTS.md`: tabla de mejoras, con una variable por fila.
